# query.academy — Android app

A real native Android app (built with Capacitor, not a browser wrapper)
for the query.academy learning platform. The web app's files are bundled
**inside** the app itself, so it works offline from the very first launch —
no prior internet visit required. Signing in uses the same account system
as the website, so one account works on both.

## Project layout

- `www/` — the actual app content (HTML/CSS/JS + PHP API), bundled into the
  app. This is a copy of the main query.academy project.
- `android/` — the real native Android Studio project (generated by
  Capacitor, editable like any other Android project if you ever want to
  open it directly in Android Studio)
- `assets/` — source icon/splash images (1024×1024 and 2732×2732) used to
  generate every density Android actually needs
- `.github/workflows/build-android.yml` — builds a real, installable `.apk`
  automatically, using GitHub's own servers (which have the Android SDK —
  most local machines and sandboxes don't)

## Getting an APK — the fast path

You don't need Android Studio installed for this.

1. Push this project to a GitHub repository (create one at github.com if
   you don't have one — it's free)
2. Go to the repo's **Actions** tab — the workflow runs automatically on
   push, or click **Run workflow** to trigger it manually
3. Once it finishes (a few minutes), click into the run → scroll to
   **Artifacts** → download `query-academy-debug-apk`
4. That's a real `.apk` file. Transfer it to an Android phone (email it to
   yourself, Google Drive, USB, whatever's easiest) and tap to install —
   Android will ask you to allow "install from unknown sources" for that
   one install, since it's not from the Play Store (yet)

That gets you a genuinely installable app today, works offline, no
Play Store needed.

## Before you build for real use

**Edit `www/script.js`** — search for `REMOTE_API_BASE` near the top and
change the placeholder URL to your actual deployed domain (wherever you
host the PHP backend from the main project). This is what lets the app
reach your real server for sign-in/registration while its pages themselves
are bundled locally.

Then re-sync before the next build:
```
npm install
npx cap sync android
```
(The GitHub Actions workflow does this step automatically on every run —
you only need to run it yourself if testing locally.)

## Getting it onto the Play Store

See **ANDROID_RELEASE_SETUP.md** — that's the part that needs a signing
key (yours to generate and keep, forever) and a Google Play Developer
account ($25 one-time, requires your own identity/payment — not something
that can be set up by anyone but you). Everything else (the actual app,
the build automation, the store assets) is already done.

## Updating the app later

Whenever the main query.academy project changes, copy the updated files
into this project's `www/` folder, then push — the GitHub Actions workflow
picks it up and rebuilds automatically.
